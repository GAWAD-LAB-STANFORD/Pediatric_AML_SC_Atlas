# Figure S8 — strict-LSC candidates are not primitive quiescent LSC

Current analysis (49-state scheme). The panels ask whether the strict marrow-sparing surface-target
candidates mark a primitive quiescent LSC compartment; they do not — the candidates sit between
primitive HSC and committed GMP, co-expressing GMP/granule markers.

## Panels & the source data each reads (`scripts/` read `../source_data/`)
- `panel_strictLSC_markers.R` → **`strictLSC_marker_profile.csv`** (shipped here). Dot plot of the four
  marker modules across normal HSC (primitive) / strict-LSC candidates (n=26) / normal GMP (committed).
- `panel_strict_lsc_funnel.R` → strict-LSC gating funnel.
- `panel_strict_lsc_umap.py` → reads `strict_LSC_barcodes.csv` (a derived barcode list).
- `composite_figS_lsc.py` → assembles the panels.

## Provenance of the strict-LSC intermediates
`compute_strict_lsc.py` regenerates the barcode/funnel/marker intermediates directly from the atlas
h5ad (input: `normal_HSC_gated_barcodes.csv`, shipped at `08_Source_Data/Figure_2/v3/`), writing
`strict_LSC_funnel.csv`, `strict_LSC_barcodes.csv`, and `strictLSC_marker_profile.csv`. The
marker-profile CSV is committed here (authoritative copy: `08_Source_Data/Figure_3/v3/`); the
per-cell barcode lists are large derived files regenerated by the compute script rather than shipped.
