# Figure S8 — Absence of a primitive quiescent LSC population

**Self-contained.** Reproduces deployed **Figure S8** (`../../05_Supplementary_Figures/Figure_S8__LSC_scarcity.pdf`) from its own source data.
Part of the atlas/prognosis analysis stream (legacy Figure_1-4 pipelines); scripts here are copies so this figure stands alone.

## Reproduce
```bash
cd scripts
python composite_figS_lsc.py
```
Reads `../source_data/` and writes `../figures/`.

## Note
Panel builders read the scanpy atlas (config H5); composite stitches the rendered panels.

## Provenance note for panel A (strict-LSC funnel)
`panel_strict_lsc_funnel.R` carries the gate counts inline (AML 28304 / 13194 / 95 / 78 / 26;
healthy BM 812 / 518 / 160 / 102 / 2) rather than reading a source-data table. They are the
output of `compute_strict_lsc.py`, which needs the raw scanpy atlas (config `H5`, deposited to
GEO); `strict_LSC_funnel.csv` and `strict_LSC_barcodes.csv` are regenerated by that script and
are not shipped here. `strictLSC_marker_profile.csv` IS shipped, so the marker panel renders
from source data alone, while panel A's funnel and the strict-LSC UMAP require the raw atlas.
