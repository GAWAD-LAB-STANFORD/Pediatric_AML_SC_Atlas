# Figure S19 — composite candidates versus antigens already in clinical trials (Venn)

Venn overlap between the antigens already in interventional AML trials and the
candidates nominated by the composite surfaceome screen.

Source data in this folder:
- `fig_aml_trials.csv`    — the clinical-trial antigen landscape (also used by Figure S18)
- `fig5A_top15.csv`       — the composite discovery ranking the candidate set is drawn from

Rendered by `../../07_Code/Figure_S19/scripts/figS_venn.R`.

The panel itself has no separate numeric table; the two inputs above are the data
behind it.
