# Figure S12 — CITE-seq surface-protein validation of the T/NK subsets

Antibody-derived-tag surface-protein measurements across the annotated T and NK
subsets, validating the transcriptional subset assignments.

Source data in this folder:
- `figS11_tnk_surface_percell.csv`     — per-cell ADT values for the T/NK compartment
- `figS11_surface_pct_by_subset.csv`   — percentage positive per surface marker, per subset

The `figS11_` filename prefix predates a figure renumbering; the files belong to
Figure S12 as numbered in the submitted manuscript. They are read by
`../../07_Code/Figure_S12/scripts/build_figS11_citeseq.py`.
