# Figure S11 — CITE-seq normalization and gating

Antibody-derived-tag (ADT) normalization and the gating used for the CITE-seq panels.

No plot-level table ships for this figure. The panels are produced directly from the
CITE-seq object by `../../07_Code/Figure_S11/scripts/build_figS11_citeseq.py`, which
reads the AnnData/muon object from the documented staging path `../../raw/` rather
than from this folder. That object is repository-scale and is deposited to GEO rather
than shipped with the source data; see the data-availability statement.

The downstream surface-protein tables derived from the same object ship with
Figure S12.
